# 华夏历史时间线 - Nuxt 开发需求文档

## 一、项目概述

### 1.1 项目名称

华夏历史时间线（Chinese History Timeline with Videos）

### 1.2 项目描述

一个交互式的中国历史时间线展示平台，通过可视化时间轴、历史事件卡片和视频播放功能，让用户直观地了解和学习中国历史发展脉络。

### 1.3 项目定位

- 教育展示型网站
- 响应式设计（支持桌面端和移动端）
- 中国传统文化风格设计（水墨、宣纸质感）

---

#### 4.2.2 时间轴可视化（Timeline）

**设计要求**：

- 每个时期一条水平时间线（4px 高度）
- 时间线颜色：对应时期的主题色（30%透明度）
- 时间轴点（Timeline Dots）：
  - 圆形，8x8 尺寸
  - 背景色为时期主题色
  - 4px 宣纸色边框
  - 内含播放图标（三角形）
  - Hover 效果：放大 1.3 倍，添加阴影
  - 点击后播放对应时间点的视频

**时间轴点位置分布**：

- 古代史：7 个点，均匀分布（0%, 16.67%, 33.33%, 50%, 66.67%, 83.33%, 100%）
- 中古史：7 个点，均匀分布
- 近代史：5 个点（0%, 25%, 50%, 75%, 100%）
- 现代史：3 个点（0%, 50%, 100%）

#### 4.2.5

搜索功能

**搜索范围**：

- 事件标题
- 事件年份
- 事件描述

**搜索行为**：

1. 实时搜索（input 事件触发）
2. 隐藏不匹配的事件卡片和时间轴点
3. 显示匹配的事件卡片和时间轴点
4. 搜索结果为空时显示"无结果"提示
5. 清空搜索词时恢复原始显示

**搜索布局调整**：

- 单个结果：卡片保持默认宽度
- 多个结果：卡片固定宽度 350px，使用 auto-fill 布局
- 时间轴点位置动态调整（与对应卡片的 offsetLeft 对齐）

**与筛选器联动**：

- 搜索时同时考虑当前选中的时期筛选
- 只在当前筛选时期内搜索

**筛选按钮状态**：

- 默认状态：墨色背景 10% 透明度
- 激活状态：时期主题色背景 + 宣纸色文字

**筛选行为**：

1. 点击筛选按钮
2. 更新按钮激活状态
3. 更新页面标题
4. 显示/隐藏对应时期的事件卡片

#### 4.2.7 滚动相关功能

**1. 滚动显示动画（Scroll Reveal）**

- 初始状态：透明度 0，向左偏移 50px
- 进入视口后：透明度 1，位置归位
- 过渡时间：0.8s ease
- 触发条件：元素距离视口底部 < 150px

**2. 回到顶部按钮**

- 显示条件：页面滚动超过 300px
- 位置：固定在右下角
- 点击行为：平滑滚动到页面顶部

## 七、核心 Composables 实现参考

### 7.1 筛选和搜索

```typescript
// composables/useFilter.ts
export const useFilter = () => {
  const activePeriod = ref("all");
  const searchTerm = ref("");
  const eventsData = ref<HistoricalEvent[]>([]);

  const filteredEvents = computed(() => {
    return eventsData.value.filter((event) => {
      const matchesPeriod =
        activePeriod.value === "all" || event.period === activePeriod.value;

      const matchesSearch =
        !searchTerm.value ||
        event.title.toLowerCase().includes(searchTerm.value.toLowerCase()) ||
        event.description
          .toLowerCase()
          .includes(searchTerm.value.toLowerCase());

      return matchesPeriod && matchesSearch;
    });
  });

  return { activePeriod, searchTerm, filteredEvents, eventsData };
};
```

### 7.2 视频播放

```typescript
// composables/useVideoPlayer.ts
export const useVideoPlayer = () => {
  const isModalOpen = ref(false);
  const currentVideo = ref<any>(null);

  const openVideo = (event: HistoricalEvent) => {
    currentVideo.value = event;
    isModalOpen.value = true;
  };

  const closeVideo = () => {
    isModalOpen.value = false;
    currentVideo.value = null;
  };

  return { isModalOpen, currentVideo, openVideo, closeVideo };
};
```

## 十一、注意事项

1. **视频播放**：B 站视频可能存在跨域问题，需要测试 iframe 嵌入的可行性
2. **性能优化**：历史事件数据较多时，考虑虚拟滚动或分页加载
3. **移动端体验**：确保触摸操作流畅，时间轴点击区域足够大
4. **字体加载**：考虑字体加载失败的降级方案
5. **SEO 优化**：使用服务端渲染确保内容可被搜索引擎抓取
